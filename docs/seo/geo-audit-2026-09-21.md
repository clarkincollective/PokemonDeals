# Technical SEO / GEO audit - 2026-09-21

Full repository + production audit. Verdict: **PASS WITH ISSUES**, three
fixed during the audit, the rest recorded below.

## The finding that mattered

**Every page that named the Organization as its publisher failed to
define it.** `/about`, `/contact`, `/how-it-works`, `/methodology`, every
guide (`components/GuideLayout`) and every Dataset page
(`/market-data/*`, `/integrity`) emitted

    "publisher": { "@id": "https://pokemondealfinder.com/#organization" }

while the Organization node itself existed only on the home page. A bare
`@id` with no matching node in the same document is an unresolved
reference: the byline on every guide, and `creator`/`publisher` on the
original research, pointed at nothing.

`lib/jsonLd.js` already shipped `unresolvedReferences()` to catch exactly
this. It was only ever applied to the home graph.

Fixed: `publisherNode()` delegates to `organizationNode()` with the
verified `sameAs` list, so inner pages emit the SAME identity rather than
a thinner second one. `tests/scanner/publisher-resolution-2026-09-21`
applies the rule to every referencing page by source inspection.

Verified in production on all six page families: referenced = defined,
dangling = none.

**Second identity defect:** news articles inlined an anonymous
`{"@type":"Organization", name, url}` with no `@id` - a *different*
entity from the one the rest of the site names. Now references the
canonical `@id`.

## Also fixed

**AI referral granularity.** `traffic_source` collapsed ChatGPT,
Perplexity, Gemini, Copilot and Claude into one `ai_assistant` bucket, so
"which AI systems send visitors who go on to click a listing" was
unanswerable. `ai_source` names the assistant from a fixed five-value
vocabulary - never a host, URL or free text, set only when the traffic is
already classified as an assistant, omitted entirely otherwise.
Unrecognised sources return null rather than a guess.

## Deliberately NOT changed

- **AI crawler policy.** Every agent is currently allowed, including
  training-only crawlers (CCBot, meta-externalagent, cohere-ai,
  Google-Extended, Applebot-Extended). Narrowing these to
  search/retrieval-only is a **business decision**, not a technical one,
  and the evidence either way is weak: training access produces no
  citations or referrals, but exclusion may remove the brand from corpora
  entirely. The current policy is deliberate and documented in
  `app/robots.js`, not accidental. Left for the owner.
- **`Bingbot` listed among `AI_AGENTS`.** Conceptually a classic search
  crawler, not an AI agent. Functionally harmless (identical rules), so
  renaming the constant is churn.
- **Home canonical** is `https://pokemondealfinder.com` where the sitemap
  says `.../`. Identical URLs per RFC 3986; normalising is cosmetic.
- **Merchant Listing schema.** Correct; the brief flags it as previously
  corrected. Not touched.
- **`hasMerchantReturnPolicy` / `shippingDetails`** on Offers: we are not
  the merchant, eBay is. Adding them would assert something untrue.
- **A public data API.** No demonstrated consumer, and it is scraping
  amplification with real database cost. The Dataset pages already expose
  the figures with a licence.
- **Deal matching, scanning, price calculation, affiliate attribution,
  social publishing, safety holds.** Out of scope by instruction.
