# UI audit — 2026-09-20

Owner brief: "audit our website UI, make sure it's premium, the best on the
market." Method: production pages at 1440×900 (screenshots where the
browser renderer allowed; the homepage and /deals grid timed out the
screenshot channel repeatedly, so those two were audited from DOM
metrics run in the page plus code review), a 390 px frame for phone
layout, and the component source. Comparators: the design system in
`docs/design/redesign-2026-09.html` (the target look) and the general bar
set by best-in-class data products, not other Pokemon deal sites.

## What already holds up
- One typeface system (Sora display, Inter Tight UI, JetBrains Mono for
  figures), one radius scale (6 / 8 / 12 px), one shadow (card hover),
  blue-black neutrals with a single lime accent and amber for auctions.
  No off-palette colours were found in the computed styles.
- Focus-visible outlines on every control; 44 px header controls; the
  mobile filter sheet with focus trap and Escape.
- Guide pages: clear hierarchy, ~65-character measure, figures with real
  captions. Card art now on every guide.

## Findings and what changed (commit `1f00d74`)

| # | Finding (evidence) | Fix |
|---|---|---|
| 1 | **Flag emoji do not render on Windows.** 12 render sites used `MARKETPLACES[x].flag` (🇺🇸 …). Windows Chrome/Edge have no flag glyphs and show two regional-indicator letters instead, so desktop visitors saw letter boxes in every deal card badge, the header marketplace control, filter pills and deal pages. | `components/MarketplaceMark.js`: the two-letter marketplace code set in the mono face inside a hairline box (a globe glyph for "all"). Rendered identically on every platform; aria-hidden beside the words that carry the meaning. `REGIONS` gained `short`. `<option>` lists keep the label only. |
| 2 | **Type too small and too uniform.** Computed font sizes: /deals 12 px on 401 of ~590 text elements, 14 px on 99, 16 px on 51; home 12 px × 230, plus 24 uses of 10 px, one 9 px, one 8 px. Premium data UIs hold 13–14 px for secondary text and reserve ≤ 12 px for labels. | Interface text floor 11 px (SVG diagram and chart labels excluded). Deal card set/condition, market reference, saving and status lines 13 px. Home answer capsule 13 px. Pinned by test. |
| 3 | **Filter pills were 26 px tall, 12 px text** (136 interactive targets under 32 px on /deals). | Pills 13 px text, `min-h-8` (32 px), wider padding. |
| 4 | **/deals: no listing above the fold at 1568×772.** Hero + 12 category chips + a five-row filter panel (Sort, Marketplace with explanatory paragraph, Card & listing, Price, Search within) filled the first screen. | `FilterBar sortOutside`: Sort stays as a slim toolbar with the Filters button beside it; the other rows sit behind the button (inline on desktop, bottom sheet on phones); every row stays in the DOM. |

## Findings left as they are, with reasons
- **Homepage weight.** 869 visible elements, 24 images, first paint fine;
  the screenshot channel's timeouts are the extension's renderer, not a
  page fault (the same page scores well in earlier LCP checks). Not
  changed.
- **Catalogue card page's graded empty state** ("No graded tier has
  enough reliable recent sales…") stays as a sentence inside the
  Condition & graded references block: it is the honest answer to the
  section's question, and the R3 harness pins that block.
- **Sealed deal card's stacked badge** ("NN% / BELOW MARKET") differs from
  the card grid's percent-only badge. Its label rose from 8 px to 11 px;
  unifying the two badge systems is a follow-up, not a defect.
- **Other emoji**: the globe in the marketplace control is now an SVG;
  the 🇯🇵 prefix on Japanese cards' set lines (the same Windows problem)
  was removed in the follow-up commit - "Japanese ·" in words already
  said it; the ♡ Saved glyph renders everywhere and stays.
